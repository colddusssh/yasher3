
# Ящер3

**Ящер3** — это славянский диалект языка программирования Python.  
Позволяет писать код на великом и могучем, сохраняя всю мощь оригинального Python.

## Пример

```python
внедрить времечко

молвить("Здрав буди, мил человек!")
имя = внемлить("Как величать тебя? ")

коли имя:
    молвить(f"Славься, {имя}!")
отнюдь:
    молвить("А ты, выходит, безымянный...")

время = времечко.времечко()
молвить(f"времечко: {время}")
```

## Требования

- **Python 3** (проверьте: `python --version` или `python3 --version`).
- Операционная система: Windows, Linux, macOS (везде, где работает Python).

## Установка

### Windows (автоматическая)

В папке `installers` находится установщик для Windows.  
Просто запустите `yasher3_installer_win.bat` 
Скрипт скачает последнюю версию `ящер3.exe` и добавит её в `PATH`.  
После установки перезапустите командную строку и проверьте:

```cmd
ящер3
```

### Другие ОС (Linux / macOS)

```bash
curl -L -o ящер3 https://github.com/colddusssh/yasher3/raw/refs/heads/main/bin/ящер3
chmod +x ящер3
sudo mv ящер3 /usr/local/bin/
```

Убедитесь, что Python 3 доступен в системе.

## Использование

Запуск файла со славянским кодом:

```bash
ящер3 файл.русь
```

Интерактивный режим (REPL):

```bash
ящер3
```

## Словарь

Основные соответствия можно найти в файле `source/main.py`. (words)
Например:

- `молвить` → `print`
- `коли` → `if`
- `покуда` → `while`
- `внедрить` → `import`
- `целина` → `int`
- `времечко` → `time`
- и многие другие.
